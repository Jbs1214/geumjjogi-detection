# tracking

담당: 김민영. 좌표 변환·ROI 지정·추적·우회전 이벤트 추출.

| 파일 | 하는 일 | 상태 |
| --- | --- | --- |
| `homography.py` | 출구 횡단보도 네 모서리(픽셀)와 실측 폭·길이(m)로 픽셀 → 미터 변환 | 구현 |
| `roi_tool.py` | 영상 한 장면에서 횡단보도·진입로·정지선·신호등을 클릭해 `configs/site_<영상>.yaml` 생성 | 구현 |
| `track.py` | YOLO + ByteTrack 추적, 박스 하단 중심점을 미터 좌표로 | 구현 |
| `events.py` | 진입로 ROI를 지난 뒤 출구 횡단보도에 들어간 궤적을 우회전 이벤트로 추출 | 구현 |

## ROI 도구 (`roi_tool.py`)

프로그램은 화면에서 횡단보도나 도로를 스스로 찾지 못한다. 사람이 영상 한 장면에서 위치를 클릭해 알려 주고 그 결과를 `configs/site_<영상>.yaml`에 저장한다. 위치 지정이지 측정이 아니다. 거리는 이 파일의 실측치로 `homography.py`가 계산한다. `track`·`events`·`traffic_light`·`features`·`rules`가 모두 이 파일을 `--site`로 읽는다.

- **영상마다 1개** 만든다. 화각이 같은 영상(카메라를 움직이지 않고 이어 찍은 영상)은 파일을 복사해서 쓴다.
- 분석할 영상 모두 site 파일이 있어야 `track`을 돌릴 수 있다. 영상당 몇 분 걸린다.

### 실행

```bash
conda activate geumjjogi-detection
# 처음 만들기 (실측치를 알면 같이 넣는다)
python -m tracking.roi_tool --video <영상 경로> --out configs/site_A_20261107_0800.yaml --width-m <실측 폭> --length-m <실측 길이>
# 일부만 다시 찍기 (예: 신호등만)
python -m tracking.roi_tool --video <영상 경로> --out configs/site_A_20261107_0800.yaml --only signal
```

| 인자 | 내용 |
| --- | --- |
| `--video` | 원본 영상. 장면을 읽기만 하고 영상은 바꾸지 않는다. 레포 밖(T5 SSD 등)에 두고 경로만 넘긴다 |
| `--out` | 저장할 site 파일. 이름은 영상 이름과 맞춘다 (`A_20261107_0800.mp4` → `site_A_20261107_0800.yaml`) |
| `--width-m` | 출구 횡단보도 ①→② 변(화면 기준 좌상→우상)의 실측 길이(m). 생략 가능 (아래 "실측치") |
| `--length-m` | 출구 횡단보도 ①→④ 변(화면 기준 좌상→좌하)의 실측 길이(m). 생략 가능 |
| `--frame-sec` | 처음 보여 줄 장면의 시각(초). 기본 0 (첫 장면) |
| `--only` | 이미 만든 `--out` 파일에서 고를 영역만 다시 찍는다. `crosswalk` `exit_area` `others` `approach` `stop_line` `signal` 중 여러 개. 나머지 값은 그대로 둔다 |

- `site` 값(교차로 이름)은 영상 이름의 첫 부분(`A_…` → `A`)에서 가져온다. 파일 이름이 규칙과 다르면 저장 후 yaml에서 고친다.
- 클릭하지 않는 값(`camera_moved_s`, `right_turn_signal`, 판정 기준값)은 `configs/site_example.yaml`의 값이 그대로 들어간다. 영상을 보고 yaml에서 직접 고친다.
  - `camera_moved_s`: 영상 안에서 카메라가 움직인 구간 `[[시작초, 끝초], ...]`. 없으면 `[]`.
  - `right_turn_signal`: 우회전 전용 신호가 있는 교차로면 `true`.

### 실측치

- 실측(폭·길이)은 **출구 횡단보도 하나만**, **교차로당 한 번**이면 된다. 같은 횡단보도면 영상이 달라도 값이 같다. 다른 횡단보도는 실측하지 않는다.
- 클릭은 먼저 하고 실측치는 나중에 채워도 된다. `--width-m`, `--length-m`을 생략하면 `0.0`으로 저장되고 경고가 나온다.
- 실측치가 나오면 yaml의 `crosswalk.width_m`, `crosswalk.length_m` 두 숫자만 고친다. 또는 `--only crosswalk --width-m … --length-m …`로 모서리를 다시 찍으면서 넣는다.
- 실측치가 0인 파일로 `track`을 돌리면 homography가 에러로 멈춘다. 잘못된 거리로 분석되지 않는다.
- 임시값(실측 아닌 값)으로 만든 파일은 커밋하지 않는다.

### 어느 횡단보도를 찍나

1단계는 **우회전 경로가 지나는 횡단보도 전부**를 판정한다 (`docs/judgment_criteria.md`). 영상에서 우회전 차 한 대를 처음부터 끝까지 따라가며 밟는 횡단보도를 모두 찾는다.

| 횡단보도 | 찍는 곳 |
| --- | --- |
| 출구 횡단보도: 다 꺾고 새 도로에 들어선 뒤 **마지막으로** 지나는 곳 | 1단계 `EXIT CROSSWALK` (네 모서리) |
| 그 밖에 우회전 차가 지나는 곳: 진입 쪽(정지선 바로 다음), 꺾는 도중(스크램블의 대각선 등) | 3단계 `OTHER CROSSWALKS` (다각형, 여러 개) |
| 우회전 차가 지나지 않는 곳 | 찍지 않는다 |

- 다른 횡단보도는 화면에 다 담기지 않거나 가려져도 **보이는 부분만** 찍는다. 전혀 안 보이면 넣지 않는다.
- 출구 횡단보도는 미터 좌표의 기준이라 네 모서리가 모두 보여야 한다.

### 클릭 순서

창 왼쪽 위에 지금 단계(`STEP 1/6 …`), 찍은 점 개수, 키 안내가 나온다. 터미널에도 한글 안내가 나온다.

| 단계 | 화면 이름 | 찍을 곳 | 점 | 건너뛰기 |
| --- | --- | --- | --- | --- |
| 1 | `EXIT CROSSWALK` | **출구 횡단보도** 네 모서리. 양쪽 블록 열에 블록이 모두 있는 행만 감싸는 직사각형 | 4 | 불가 |
| 2 | `EXIT AREA` | 출구 판정 영역(선택). 사각형 밖으로 나온 블록까지 보이는 블록 전체 테두리 (아래 "출구 판정 영역") | 3 이상 | `s` (사각형과 같음) |
| 3 | `OTHER CROSSWALKS` | 출구 말고 우회전 차가 지나는 횡단보도. 하나씩 보이는 부분을 감싸는 다각형 | 하나당 3점 이상 | `s` (하나도 없음) |
| 4 | `APPROACH` | 우회전 진입로: 우회전 차로부터 정지선을 지나 꺾기 시작하는 곳까지, 우회전 경로만 좁게(차 한 대 폭). 정지선 근처에서 검출이 끊겨도 우회전을 잡기 위함. 출구 횡단보도에 닿지 않게 | 4 | 불가 |
| 5 | `STOP LINE` | 정지선 양 끝 (2단계 판정용). 정지선이 없으면 **진입 쪽 횡단보도 앞 가장자리** 두 점 | 2 | `s` |
| 6 | `TRAFFIC LIGHT` | 우회전 차량이 보는 **차량** 신호등(원형 3색)을 감싸는 사각형 (2단계 판정용). 보행자 신호등 아님 | 4 | `s` |

3단계는 횡단보도를 여러 개 찍는다.

1. 횡단보도 하나의 보이는 부분 테두리를 3점 이상 찍고 `Enter`.
2. **터미널**을 클릭해 이름을 입력하고 `Enter` (그냥 `Enter`면 `cw1`, `cw2`…). 예: `near`(진입 쪽), `diag`(대각선). `exit`는 출구 횡단보도 이름이라 쓸 수 없다.
3. 다음 횡단보도를 찍는다. 다 찍었으면 창을 다시 클릭하고 점 없이 `Enter`.

| 조작 | 키 |
| --- | --- |
| 점 추가 | 왼쪽 클릭 |
| 마지막 점 취소 | 오른쪽 클릭 |
| 다음 단계 (점을 다 찍었을 때만) | `Enter` |
| 건너뛰기 (2·3·5·6단계만) | `s` (3단계에서는 찍어 둔 다각형도 버린다) |
| 판정 영역 마무리 (3점 이상) | `Enter` |
| 저장하지 않고 종료 | `Esc` |
| 확대·축소 (커서 위치 기준, 최대 8배) | 마우스 휠 |
| 확대한 화면 이동 | 가운데 버튼(휠 누르기) 끌기 |
| 5초 뒤 / 앞 장면 | `n` / `b` |

- 확대한 상태에서 찍어도 좌표는 원본 해상도 기준으로 저장된다. 멀리 있는 모서리·신호등은 확대해서 찍는다.
- 차나 사람이 모서리를 가리면 `n`/`b`로 장면을 넘긴다. 카메라가 고정이라 이미 찍은 점은 그대로 둔다. 현재 시각은 안내 줄의 `t=…s`.
- `--only`로 열면 다시 찍지 않는 영역도 화면에 같이 그려진다. `--only others`는 다른 횡단보도를 전부 새로 찍는다(기존 것은 지워진다).

### 모서리 찍는 법 (출구 횡단보도)

```text
      ①좌상 ───── ②우상          ① → ② → ③ → ④ (화면 기준 시계 방향)
       ╱            ╲
      ╱   횡단보도    ╲
   ④좌하 ────────── ③우하
```

- 좌상·우상은 **화면에 보이는 그대로**의 위·아래·왼쪽·오른쪽이다. 실제 방향과는 관계없다.
- 횡단보도가 비스듬하면 화면 위쪽에 가까운 모서리를 ①로 정하고 시계 방향으로 돈다. 순서가 꼬이면(Z자) 좌표가 무한대로 틀어지므로, 찍은 뒤 선이 엇갈리지 않은 사각형인지 확인한다.
- 모서리는 흰 줄무늬 전체를 감싸는 바깥 사각형의 꼭짓점이다 (가장 바깥 줄무늬의 바깥 끝). 다른 횡단보도도 같은 바깥 테두리를 찍는다.
- 실측할 사람에게 화면 기준 ①→② 변과 ①→④ 변을 알려 줘야 `--width-m`, `--length-m`이 맞게 들어간다.

### 출구 판정 영역 (`area_px`, 선택)

네 모서리(`corners_px`)는 실측 크기를 아는 **직사각형**이어야 homography가 맞다. 그런데 연석이 둥근 교차로는 왼쪽·오른쪽 블록 열이 시작하는 행이 달라(예: 왼쪽 35행, 오른쪽 37행) 횡단보도 전체가 직사각형이 아니다.

- 네 모서리: 양쪽 열에 블록이 **모두 있는 행만** 감싼다. ①②는 그 첫 행의 위쪽 바깥 끝(같은 행), ④③은 마지막 행의 아래쪽 바깥 끝(같은 행). `--length-m`은 그 행 수 n으로 계산한다 (n × 블록 두께 + (n−1) × 줄 사이 틈).
- 판정 영역: 사각형 밖으로 나온 블록까지 **보이는 블록 전체**의 바깥 테두리를 3점 이상으로 감싼다. 판정(출구 진입, 그 위 보행자)은 이 영역으로 한다(기술서 2.2 횡단보도 전체).
- 사각형을 전체 폭으로 늘리면 안 된다. 블록이 없는 쪽 인도가 들어가 신호를 기다리는 사람이 보행자로 세어진다.
- 횡단보도가 직사각형이면 `s`로 건너뛴다(빈 값 → 네 모서리로 판정).

### 결과 파일 예

```yaml
# tracking.roi_tool 로 생성: A_20261107_0800.mp4
site: A
crosswalk:
  corners_px:            # 원본 해상도 픽셀 좌표 (화면이 줄어 보여도 원본 기준으로 저장)
  - [800, 400]
  - [1120, 400]
  - [1600, 900]
  - [320, 900]
  area_px: []            # 선택. 비우면 corners_px로 판정
  width_m: 4.0
  length_m: 10.0
other_crosswalks_px:     # 이름: 보이는 부분 다각형. 없으면 {}
  near: [[...], [...], [...], [...]]
  diag: [[...], [...], [...], [...], [...]]
camera_moved_s: []       # 영상을 보고 직접 적는다
approach_roi_px: [...]
right_turn_signal: false # 영상을 보고 직접 적는다
stop_line_px: []         # 건너뛰면 빈 값
signal_roi_px: [...]
stop_speed_mps: 0.5      # 이하 기준값은 configs/site_example.yaml에서 복사
stop_min_duration_s: 1.0
stopline_zone_m: 3.0
occluded_edge_m: 1.0
signal_min_frames: 5
```

### 주의

- 원본 프레임 캡처를 Drive·Discord·AI 채팅 등 외부에 올리지 않는다 (얼굴·번호판).
- 모서리가 4개가 아니거나 실측치가 음수면 저장하기 전에 에러로 멈춘다.
