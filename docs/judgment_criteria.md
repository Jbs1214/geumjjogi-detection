# MVP 판정 기준표

> 담당: 육주영 · **11.09 팀 합의로 확정** (그 전까지는 초안). 기획서 3-2절을 옮긴 것이다.
> 이 기준은 영상 분석용 정의이며 **법적 위반 판정이 아니다.**

| 구분 | 정의 |
| --- | --- |
| 대상 | 우회전 후(출구 쪽) 횡단보도 1개 |
| 충돌 구간 | 출구 횡단보도 중 우회전 차량의 진행 차로와 겹치는 부분에 양옆 약 3 m(1차로 폭)를 더한 영역. 정확한 폭은 시험 영상으로 확정 |
| 양보 대상 이벤트 | 우회전 차량(오토바이 포함)이 횡단보도 접근 구간에 들어온 뒤 횡단보도 영역에 진입하기 전까지, 충돌 구간 안에 보행자가 1명 이상 있었던 경우. 접근 시점 이후에 충돌 구간에 들어온 보행자도 포함 |
| ✅ 양보 (`yield`) | 보행자가 충돌 구간 안에 있는 동안 차량이 횡단보도 영역에 진입하지 않고 정지(속도 0.5 m/s 이하가 1초 이상)했다가, 보행자가 충돌 구간을 벗어난 뒤 진입 |
| ❌ 미양보 (`no_yield`) | 보행자가 충돌 구간 안에 있는 동안 차량이 횡단보도 영역에 진입해 통과 (감속 후 진입해도 미양보) |
| ➖ 제외 (`exclude`) | 충돌 구간 안에 보행자가 없는 경우(먼 쪽 구간·인도 대기만 있는 경우 포함), 보행자가 가려져 판단할 수 없는 경우, 우회전 이벤트가 아닌 경우 |
| 양보율 | 양보 ÷ (양보 + 미양보). 제외는 분모에서 뺀다. 시간대별로 Wilson 95% 신뢰구간을 함께 표시 |

## 보충 규칙

- "횡단보도 영역 진입" = 차량 박스 **하단 중심점**이 횡단보도 영역에 들어온 시점.
- 속도·거리는 **미터 단위**(homography)로 계산한다. 픽셀 단위 속도는 쓰지 않는다.
- 정지 기준(0.5 m/s, 1초)과 충돌 구간 폭(3 m)은 초기값이다. 값은 `configs/site_*.yaml`에 두고 시험 영상으로 조정한다.
- 오토바이 박스와 크게 겹치는 `person` 검출은 운전자로 보고 보행자에서 뺀다.
