# MVP 판정 기준표

> 담당: 육주영 · **11.09 팀 합의로 확정** (그 전까지는 초안). 기획서 3-2절, 기술서 2.2절을 옮긴 것이다.
> **11.10 수정:** 접근 구간을 없앴다. 1단계는 진입 순간 보행자 유무만 보고, 보행자가 없던 우회전도 판정 대상(양보 = 위반 아님)에 넣는다(기술서 11.1).
> 이 기준은 영상 분석용 정의이며 **법적 위반 판정이 아니다.**

| 구분 | 정의 |
| --- | --- |
| 대상 | 우회전 후(출구 쪽) 횡단보도 1개. **횡단보도 전체**를 본다(충돌 구간 같은 일부 영역이 아님) |
| 판정 대상 이벤트 | 출구 횡단보도에 진입한 우회전 차량(오토바이 포함) 전부. 아래 제외 사유에 해당하는 것만 뺀다 |
| ✅ 양보 (`yield`, 위반 아님) | 진입 순간 횡단보도 위에 보행자가 **없음**. 보행자가 있는 동안 기다렸다가 진입한 경우와 처음부터 보행자가 없던 경우를 모두 포함 |
| ❌ 미양보 (`no_yield`, 위반 의심) | 진입 시점에 횡단보도 위에 보행자가 한 명이라도 있음 (감속 후 진입해도 미양보. 먼 쪽 차로를 건너는 보행자도 포함) |
| ➖ 제외 (`exclude`) | 보행자가 보이지 않는데 가림이 의심됨, 카메라가 움직인 구간, 우회전 이벤트가 아님 |
| 위반율 | 미양보 ÷ (양보 + 미양보) = 우회전 차량 중 보행자가 있는데 진입한 비율. 제외는 분모에서 뺀다. 교차로·시간대(1시간)별로 Wilson 95% 신뢰구간을 함께 표시. 판정 대상 30건 미만인 칸은 "참고용" |

## 보충 규칙

- "횡단보도 영역 진입" = 차량 박스 **하단 중심점**이 횡단보도 영역에 들어온 시점. 보행자도 박스 하단 중심점이 영역에 들어와 있으면 횡단보도 위에 있는 것으로 센다.
- 속도·거리는 **미터 단위**(homography)로 계산한다. 픽셀 단위 속도는 쓰지 않는다.
- 1단계는 정지 여부를 보지 않는다. 정지 기준(속도 0.5 m/s 이하가 1초 이상)은 2단계에만 쓴다. 값은 `configs/site_*.yaml`의 초기값이며 시험 영상으로 조정한다.
- 오토바이 박스와 겹치는 비율이 50% 이상인 `person` 검출은 운전자로 보고 보행자에서 뺀다(초기값).
- 횡단보도 밖에서 건너려는 보행자는 MVP 대상이 아니다(한계).
- 영상 안에서 카메라가 움직인 구간(`camera_moved_s`)의 이벤트는 두 판정 모두 제외한다(기술서 1.2).
- "가림 의심" = 진입 직전 `merge_gap_s`(2초) 안에 횡단보도 위 보행자 트랙이 (끊긴 트랙 이어 붙이기 후에도) 횡단보도 경계에서 1 m(`occluded_edge_m`, 초기값)보다 안쪽에서 끝난 경우. 사람이 걸어 나가면 경계 근처에서 끝나므로, 안쪽에서 사라졌다면 진입 순간 가려져 있을 수 있다. 진입 순간 보행자가 1명이라도 보이면 가림 의심과 관계없이 미양보다.

## 2단계: 적색 신호 정지선 일시정지 (기획서 3-3절, 기술서 2.3절)

| 구분 | 정의 |
| --- | --- |
| 대상 | 차량 신호(직진 신호, 원형 3색)가 적색인 동안 정지선을 넘어 우회전한 이벤트. 우회전 이벤트를 궤적 전체로 먼저 확정한 뒤 그 이벤트에만 적용 |
| 일시정지 (`stopped`) | 빨간불일 때 정지선 직전에서 정지(0.5 m/s 이하 1초 이상)한 뒤 진행. 정지선이 없으면 진입 쪽 횡단보도 앞(교차로에 들어가기 전에 건너는 횡단보도)을 기준선으로 씀 |
| 미정지 (`not_stopped`, 위반 의심) | 빨간불일 때 정지 없이 정지선을 통과해 우회전 |
| 제외 (`exclude`) | 신호 상태 불명, 정지선이 가려짐, 우회전 전용 신호가 있는 교차로 |
| `na` | 신호가 적색이 아님(녹색·황색). 적색만 판정하므로 판정 대상이 아니다 |

- 보행자 신호등은 쓰지 않는다. 두 판정은 독립이라 한 이벤트가 두 사유를 모두 가질 수 있다.
- "정지선 직전" = 정지선 앞 3 m 이내(`stopline_zone_m`, 초기값). 기술서 11.1 보충.
- 녹색·황색 신호는 `na`로 적는다(11.10 보충: 기술서 2.3 표의 "제외"와 본문의 `na`가 달라 `na`로 맞춤. 기준 자체는 바뀌지 않음).
- 적색 위반율 = 미정지 ÷ (일시정지 + 미정지).
