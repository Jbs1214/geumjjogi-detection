# 차량 우회전 위반 감지 프로젝트 기획서

팀 금쪽같은 우리 사이 장범수(팀장), 김민영, 육주영 | 버전 2026-11-10 | 중간 발표 11.18경 · 최종 발표 2026-11-27(금)

## 1 개요

교차로 영상에서 우회전 차량이 도로교통법의 우회전 기준(횡단보도 보행자 보호, 적색 신호 정지선 일시정지)을 지키지 않은 장면을 자동으로 찾고, 교차로·시간대별 위반율을 표로 정리해 경찰이 단속 위치와 시간의 우선순위를 정하기 쉽게 제공합니다. 현장에서 바로 적발하는 시스템이 아니라 영상을 모아 분석하는 통계 도구입니다. 규칙 기반 MVP를 먼저 만들고, 이후 멀리 있는 사람과 오토바이를 놓치는 문제를 검출 모델 미세조정으로 줄입니다. 세부 기술은 별도 기술서(`spec.md`)에 정리했습니다.

| 항목 | 내용 |
| --- | --- |
| 데이터 | 부천시·김포시 교차로 중 1곳 직접 촬영(육교·건물 위 삼각대, 낮·맑은 날), 1시간 영상 약 6개. 횡단보도와 정지선, 차량 신호등이 함께 보이는 위치를 고릅니다. |
| 목표 | 미양보 F1 0.7 이상, 이벤트 추출 재현율 0.8 이상, 위반율 추정 오차 10%p 이내, 라벨러 일치도(kappa) 0.7 이상. 나머지 지표와 산정 방법은 기술서 6. |
| 산출물 | 교차로·시간대별 위반율 대시보드(Streamlit), 위반 의심 장면 클립(얼굴·번호판 블러), 오류 분석, 검출 파인튜닝 전후 비교 |
| 사용 기술 | Ultralytics YOLO, ByteTrack, OpenCV(homography), pandas, Streamlit, 로컬 라벨러 |
| 범위 밖 | 법적 위반 판정, 번호판 인식, 실시간 처리(즉시 적발), 야간·우천, 다른 교차로로의 일반화 주장 |
| 데이터 조건 | 원본 영상은 얼굴·번호판이 보여 깃·Drive·카카오톡에 올리지 않고, 비식별 처리본만 공유한 뒤 분석 후 폐기합니다. |

## 2 문제점

| 문제 | 내용 |
| --- | --- |
| 법 기준 | 우회전 운전자는 횡단보도의 보행자를 보호(도로교통법 제27조 제1항, 범칙금 6만 원·벌점 10점)하고, 적색 신호에서는 정지선에서 일시정지(2023.1.22 시행)한 뒤 우회전해야 합니다. |
| 실태 데이터 없음 | 양보 없이 진입하는 차량이 많지만 어느 교차로, 어느 시간대에 위반이 몰리는지 보여 주는 데이터가 없습니다. |
| 단속 근거 부족 | 단속 위치와 시간을 현장 인력과 신고에 의존해 정하므로, 위반율이 높은 곳을 골라 줄 객관적 자료가 필요합니다. |
| 측정 기준 없음 | "양보"의 기준이 사람마다 달라 객관적으로 재기 어렵습니다. |

출처: 정책브리핑 우회전 일시정지 개정 안내 · YTN 2026.04. 범칙금·벌점은 차종과 시기에 따라 달라 발표 전에 법령으로 다시 확인합니다. 결과는 위반 의심 장면이며 법적 판정이 아닙니다.

**그림 1. 법 기준을 영상에서 확인할 수 있는 조건으로 바꿔 지키지 않은 장면을 찾습니다.** 1단계가 MVP, 2단계가 적색 신호 정지선입니다.

| | 1단계 (MVP): ① 보행자 보호의무 | 2단계: ② 적색 신호 일시정지 |
| --- | --- | --- |
| 법 기준 | 도로교통법 제27조 제1항 | 시행규칙 신호 기준 (2023.1.22) |
| 영상에서 확인할 수 있는 조건 | 횡단보도 위 보행자 + 진입 시점에 한 명이라도 있나 | 정지선 통과 시점 차량 신호 빨간색 + 정지선 직전에서 정지 없이 통과했나 |
| 지키지 않으면 | 미양보 → 위반 의심 | 미정지 → 위반 의심 |

## 3 해결 방안

### 3-1. 영상 분석 흐름

| 단계 | 하는 일 | 핵심 기준 |
| --- | --- | --- |
| 교차로 영상 | 횡단보도·정지선·차량 신호등이 보이는 고정 영상을 받습니다. | 고정 카메라 영상 |
| 좌표 변환·ROI | 횡단보도·정지선·차량 신호등 영역을 지정합니다. | 현장 실측 치수 |
| 신호등 색 판정 | 차량 신호등(직진 신호)이 빨간색인지 판정합니다. | 2단계 |
| 검출·추적 | YOLO로 차·오토바이·사람을 찾고 추적합니다. | 미세조정은 고도화 |
| 우회전 이벤트 | 진입로→출구 횡단보도 궤적을 이벤트로 자릅니다. | ROI 규칙 |
| 위반 판정 | 정지선(빨간불) → 횡단보도(보행자) 순서로 규칙 판정합니다. | 위반 의심 |
| 위반율 대시보드 | 교차로·시간대별 위반율 표와 위반 의심 클립을 보여 줍니다. | Streamlit |

### 3-2. 1단계 MVP: 횡단보도 보행자

횡단보도 어디든 보행자가 한 명이라도 있으면 모두 지나간 뒤에 진입해야 합니다. 판정 기준은 11.09까지 팀 합의로 확정합니다.

| 판정 | 조건 |
| --- | --- |
| 양보 | 접근 중 횡단보도에 보행자가 있었고, 모두 벗어난 뒤에 진입 |
| 미양보 (위반 의심) | 횡단보도에 진입하는 시점에 보행자가 한 명이라도 횡단보도 위에 있음(감속 후 진입 포함) |
| 제외 | 접근 중 횡단보도에 보행자가 없었음, 가림으로 판단 불가, 우회전 이벤트 아님 |

위반율 = 위반 의심 ÷ 판정 대상이며, 제외는 판정 대상에 넣지 않습니다. 예: 판정 대상 10대 중 4대가 미양보이면 위반율은 40%입니다.

**판정 순서** (횡단보도 보행자, 위에서 본 그림)

```
① 접근 구간에 들어옴  (횡단보도 진입선 앞 접근 구간)
     └ 이때부터 횡단보도 위 보행자를 계속 확인
        (진입 전까지 보행자가 한 번도 없으면 → 제외)
② 횡단보도에 진입하는 순간
     └ 횡단보도 위에 보행자가 한 명이라도 있나?
            ├ 아니오 → 양보          (횡단보도 위 사람이 모두 벗어난 뒤에 진입)
            └ 예     → 미양보 (위반 의심)  (사람이 있는데 진입, 감속 후 진입도 미양보)
```

횡단보도 밖에서 기다리는 보행자는 MVP 대상이 아닙니다.

**그림 2.** 우회전 차량이 횡단보도에 진입하는 순간 횡단보도 위에 보행자가 한 명이라도 있으면 미양보, 모두 벗어난 뒤면 양보입니다.

### 3-3. 2단계: 적색 신호 시 정지선 일시정지

우회전 차량이 보는 차량 신호등(직진 신호)이 적색이면 보행자 유무와 관계없이 정지선에서 멈춘 뒤 우회전해야 합니다. 보행자 신호등은 쓰지 않고, 우회전 전용 신호가 있는 교차로는 제외합니다.

| 판정 | 조건 |
| --- | --- |
| 일시정지 | 빨간불일 때 정지선 직전에서 정지한 뒤 진행. 정지 기준과 정지선이 없을 때의 대체 규칙은 기술서 2.3. |
| 미정지 (위반 의심) | 빨간불일 때 정지 없이 정지선을 통과해 우회전 |
| 제외 | 신호 상태 불명, 정지선이 가려짐, 우회전 전용 신호가 있는 교차로 (녹색·황색 신호는 판정 대상이 아님) |

**판정 순서** (정지선, 위에서 본 그림)

```
① 차량 신호등이 적색인 채 정지선에 접근
     (직진 방향 차량 신호등 기준 · 보행자 신호등은 쓰지 않음)
② 정지선 직전에서 멈췄나?  (정지 판정 기준은 기술서 2.3)
     ├ 예     → 일시정지    (멈춘 뒤에 우회전)
     └ 아니오 → 미정지 (위반 의심)  (멈추지 않고 정지선 통과)
```

신호 상태 불명, 정지선 가려짐, 우회전 전용 신호가 있는 교차로는 제외합니다.

**그림 3.** 차량 신호가 적색일 때 정지선 직전에서 멈췄다가 우회전하면 일시정지, 멈추지 않고 지나가면 미정지입니다. 차량 신호등은 영상에서 위치를 한 번 지정해 두고, 그 영역의 색이 빨간색인지로 판정합니다.

### 3-4. 3단계: 위반율을 경찰이 보기 좋게 정리

판정 결과를 교차로·시간대별로 모아 위반율 표를 만들고, 단속 위치와 시간을 정하는 데 쓰도록 Streamlit 화면으로 제공합니다. 위반율은 위반 의심 ÷ 판정 대상이며 신뢰구간을 함께 보여 주고, 판정 대상이 적은 칸은 참고용으로 표시합니다(기준은 기술서 3.1).

### 3-5. MVP에서 고도화까지

| 단계 | 이름 | 내용 | 시점 |
| --- | --- | --- | --- |
| 0 | 촬영·기준 | 촬영 영상과 판정 기준표를 확정합니다. | ~11.09 |
| 1 | MVP | 횡단보도 보행자 양보 여부를 규칙으로 판정하고 예비 수치를 냅니다. | 11.18 (중간 발표) |
| 2 | 적색 신호 | 빨간불일 때 정지선에서 일시정지했는지 판정합니다. | 11.19~22 |
| 3 | 위반율 정리 | 교차로·시간대별 위반율을 Streamlit 대시보드로 제공합니다. | 11.23~25 |
| 4 | 검출 고도화 | 멀리 있는 사람과 오토바이를 라벨링해 YOLO를 미세조정하고 정확도를 높입니다. | 11.19~25 (병행) |
| 5 | 확대 | 교차로 추가·간 비교, 야간·우천, 신호등·정지선 자동 검출, 준실시간(엣지) | 향후 과제 |

0~4단계를 11.27까지 구현합니다. 4단계(검출 고도화)는 2·3단계와 병행해 11.25까지 끝내고, 오류가 큰 장면부터 시도합니다.

## 4 유저 시나리오

1. **영상 촬영:** 교차로 영상을 촬영해 분석 파이프라인에 넣습니다.
2. **자동 분석:** 차량·보행자를 추적하고 우회전 이벤트를 자동으로 뽑습니다.
3. **위반 판정:** 이벤트마다 보행자 미양보, 적색 미정지를 가려냅니다.
4. **대시보드 확인:** 교차로·시간대를 골라 위반율과 위반 의심 클립을 봅니다.
5. **단속 계획:** 위반율이 높은 교차로와 시간대를 단속 위치·시간 후보로 삼습니다.

| 사용자 | 얻는 것 |
| --- | --- |
| 경찰(단속 계획) | 교차로·시간대별 위반율, 신뢰구간, 위반 의심 장면 클립 |
| 교통 담당자 | 경고 표지·우회전 신호 등 시설 설치 판단 근거 |
| 프로젝트 팀 | 판정 정확도, 오류 사례 분석, 검출 파인튜닝 전후 비교 |

## 5 시스템 설계도

### 전체 구조: MVP에서 고도화로

| 순서 | 단계 | 내용 |
| --- | --- | --- |
| 1 | 촬영·기준 | 촬영 영상, 판정 기준표 |
| 2 | MVP: 횡단보도 보행자 | 진입 시점 보행자 유무 |
| 3 | 적색 신호 정지선 | 빨간불에 정지했나 |

| 6 | 검출 파인튜닝 (고도화) | 전후 재현율 비교. 결과를 규칙에 다시 적용하는 경로가 있습니다. |

### 5-1. 위반 판정

```
우회전 이벤트 (정지선 통과 ~ 횡단보도 진입)
 ├ 빨간불에 정지 없이 정지선을 통과했나?
 │     └ 예 → 미정지 (위반 의심)
 ├ (이어서 검사)
 └ 진입 시점에 횡단보도 위에 보행자가 있나?
       └ 예 → 미양보 (위반 의심)
→ 규칙 판정: 판정·사유·시각 기록 (정지선 → 횡단보도 순서)
```

두 검사는 독립이라 한 이벤트가 두 사유를 모두 가질 수 있습니다.

### 5-2. 분석·집계 데이터

```
교차로 영상 (촬영 영상, 시작 시각 기록)
 ├ 차량 신호등 색 판정: 영역 지정 → 빨간불 시간표
 ├ 검출·추적: 차량·보행자 궤적
 └ 좌표 변환: 미터 좌표, 영역 매핑
      → 우회전 이벤트: 진입로 → 출구 횡단보도 접근 구간 궤적 추출 → 이벤트 로그
      → 규칙 판정
      → 위반율 집계: 위반 의심 ÷ 판정 대상, 교차로·시간대별
```

원본 영상은 깃·Drive에 올리지 않습니다. 라벨표·집계표·비식별 클립은 Drive로 공유하고 깃에는 올리지 않습니다. 고도화 결과는 규칙에 다시 적용합니다.

### 5-3 설계 기준

| 기준 | 선택 | 근거 |
| --- | --- | --- |
| 보행자 범위 | 출구 횡단보도 전체 | 충돌 구간 같은 일부가 아니라 횡단보도 위 어디든 한 명이라도 있으면 보행자가 있는 것으로 셉니다. |
| 위치 기준점 | 지면에 닿는 점 | 차량·보행자 모두 지면에 닿는 점이 횡단보도 영역에 들어왔는지로 판단합니다(기술서 1.1). |
| 시간대 | 촬영 시작 시각 기준 | 영상마다 촬영 시작 시각을 기록해 이벤트 시각을 실제 시각으로 바꿉니다. |
| 정답 라벨 | 사람이 달고 이중 라벨로 확인 | 정답 구간 영상은 처음부터 보며 표시해 추출 재현율과 위반율 오차를 잽니다. |
| 표본 표시 | 판정 대상이 적으면 참고용 | 표본이 작으면 위반율이 크게 흔들려 신뢰구간과 함께 보입니다. 기준 건수는 기술서 3.1. |
| 고도화 | 영상 단위로 나눠 전후 비교 | 같은 영상의 프레임이 학습과 평가에 섞이지 않게 합니다. |

각 항목의 계산식과 예외 처리는 기술서에 있습니다.

### 7-4. 한계와 대응

| 한계 | 대응 |
| --- | --- |
| 일반화 | 교차로 1곳·낮·맑은 날·주말만 촬영해 평일 출퇴근은 포함하지 않습니다. 교차로 간 비교는 확장 과제로 두고, 주장 범위를 주말 낮 시간대별 비교로 한정합니다. |

| 멀리 있는 사람·오토바이 누락 | MVP는 놓친 사례를 오류로 기록하고, 고도화에서 미세조정합니다. |
| 횡단보도 밖에서 건너려는 보행자 | MVP는 횡단보도 위 보행자만 보고, 건너려는 의도는 향후 과제입니다. |
| 표본이 작은 시간대 | 신뢰구간을 함께 보이고 판정 대상이 적으면 참고용으로 표시합니다(기술서 3.1). |
| 단속 근거로 쓰기 | 결과는 즉시 적발용이 아닌 위반 의심 통계이며, 실제 단속은 별도 확인이 필요하다고 화면과 발표에 명시합니다. |
