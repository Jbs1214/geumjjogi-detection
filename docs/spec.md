# 차량 우회전 위반 감지 기술서

팀 금쪽같은 우리 사이 (장범수 팀장, 김민영, 육주영) | 버전 2026-11-10 | 저장소 github.com/Jbs1214/geumjjogi-detection

이 문서는 기획서(`plan.md`)가 가리키는 기술 내용의 기준 문서입니다. 임계값, 건수, 계산 방법은 이 문서에만 적고 기획서에는 쓰지 않으므로, 기술이 바뀌면 이 문서만 고칩니다. 표의 숫자 중 "초기값"은 시험 촬영 영상으로 조정하고, 조정하면 이 문서를 먼저 고칩니다.

## 0. 확정값 한눈에

| 항목 | 내용 |
| --- | --- |
| 감지 대상 | ① 우회전 시 횡단보도 보행자 미양보(1단계 MVP), ② 적색 신호 시 정지선 미정지(2단계) |
| 보행자 범위 | 출구 횡단보도 전체. 횡단보도 위에 한 명이라도 있으면 보행자가 있는 것으로 셈 |
| 분석 단위 | 우회전 이벤트 1건. 1단계는 출구 횡단보도 진입 순간, 2단계는 정지선 통과 순간을 봅니다 |
| 정지 기준 | 속도 0.5 m/s 이하가 1초 이상 (2단계, 초기값) |
| 판정 출력 | 보행자: 양보 / 미양보 / 제외, 정지선: 일시정지 / 미정지 / 제외(적색이 아니면 `na`). 모두 규칙 판정이며 "위반 의심" |
| 위반율 | 위반 의심 ÷ 판정 대상, 유형별·교차로별·시간대별(1시간) Wilson 95% 신뢰구간 |
| 표본 표시 | 판정 대상 30건 미만은 "참고용" (초기값) |
| 제공 방식 | Streamlit 대시보드: 교차로·시간대별 위반율 표, 단속 우선 시간대 TOP 3, 위반 의심 클립. 즉시 적발용이 아니라 단속 위치·시간의 우선순위를 정하는 통계 도구 |
| 학습 모델 | 고도화 단계의 검출 모델(YOLO) 미세조정 하나. 판정은 학습 모델 없이 규칙으로 합니다. |
| 데이터 목표 | 보행자 판정 대상 이벤트 200건 이상(미양보 50건 이상), 빨간불 중 우회전 이벤트 50건 이상 (초기값) |
| 핵심 지표 | 미양보 F1 0.7 이상, 이벤트 추출 재현율 0.8 이상, 위반율 오차 10%p 이내, kappa 0.7 이상 |

## 1. 입력과 좌표

### 1.1 검출과 추적

| 항목 | 내용 |
| --- | --- |
| 검출 클래스 | 차량(승용·버스·트럭), 오토바이, 보행자 3종. 사전학습 YOLO를 그대로 쓰고, 미세조정은 4.2의 고도화에서 다룹니다. |
| 추적 | ByteTrack으로 객체마다 ID를 붙입니다. 길이 1초 미만 트랙은 지우고, 2초 안·1.5m 안에서 끊긴 같은 종류의 트랙은 이어 붙입니다(초기값). |
| 운전자 제외 | 오토바이 박스와 겹치는 비율이 50% 이상인 person 검출은 운전자로 보고 보행자에서 뺍니다(초기값). |
| 기준점 | 위치는 박스 하단 중심점입니다. 보행자가 "횡단보도 위에 있다", 차량이 "진입했다"는 이 점이 횡단보도 영역에 들어온 것입니다. |

### 1.2 좌표 변환과 ROI

ROI 지정 도구에서 횡단보도 네 모서리를 찍어 homography를 만들고, 픽셀 좌표를 위에서 본 미터 평면으로 바꿉니다. 횡단보도 폭과 줄무늬 치수는 촬영일에 현장에서 실측합니다.

속도는 미터 좌표를 0.5초 이동평균한 뒤 차분해 m/s로 계산합니다. 픽셀 속도는 쓰지 않습니다.

ROI는 우회전 진입로, 출구 횡단보도 영역, 정지선, 차량 신호등 영역으로 나눠 YAML(`configs/site_<영상이름>.yaml`)로 저장하고 영상마다 한 번 지정합니다. 삼각대 촬영이라 영상마다 다시 찍고, 영상 안에서 카메라가 움직이면 그 구간은 제외합니다.

영상마다 촬영 시작 시각을 기록해 이벤트 시각을 실제 시각(시간대)으로 바꿉니다.

### 1.3 우회전 이벤트 추출

차량 궤적이 우회전 진입로 ROI를 지난 뒤 출구 횡단보도에 진입하면 우회전 이벤트로 봅니다. 1단계는 횡단보도 진입 순간만 보고, 정지선 통과 시각(2단계)은 궤적 전체에서 따로 찾습니다. 이벤트마다 횡단보도 진입 시각, 그 순간 횡단보도 위 보행자 수, 정지선 통과 시각, 차종, 시간대를 저장합니다.

## 2. 판정 기준

### 2.1 법규를 영상 조건으로 바꾸기

| 법적 기준 | 영상에서 확인할 조건 | 단계 |
| --- | --- | --- |
| 횡단보도를 건너는 보행자가 있으면 일시정지해 보호 (도로교통법 제27조 제1항) | 진입 시점에 횡단보도 위에 보행자가 한 명이라도 있나 | 1단계 MVP |
| 적색 신호면 정지선에서 일시정지 후 우회전 (시행규칙 신호 기준, 2023.1.22 시행) | 빨간불일 때 정지선 직전에서 정지했나 | 2단계 |

결과는 영상 분석용 위반 의심이며 법적 위반 판정이 아닙니다. 판정 기준은 11.09까지 확정하고 바꾸지 않습니다(예외 11.1).

### 2.2 1단계: 횡단보도 보행자 판정

| 용어 | 정의 |
| --- | --- |
| 판정 대상 이벤트 | 출구 횡단보도에 진입한 우회전 차량(오토바이 포함) 전부. 제외 사유에 해당하는 것만 뺍니다 |
| 양보 (위반 아님) | 진입 순간 횡단보도 위에 보행자가 없음(위반 아님). 보행자가 있는 동안 기다렸다가 진입한 경우와 처음부터 보행자가 없던 경우를 모두 포함 |
| 미양보 (위반 의심) | 진입 시점에 횡단보도 위에 보행자가 한 명이라도 있음. 감속 후 진입도 미양보 |
| 제외 | 보행자가 보이지 않는데 가림이 의심됨, 카메라가 움직인 구간, 우회전 이벤트가 아님 |

충돌 구간 같은 일부 영역이 아니라 횡단보도 전체를 봅니다. 먼 쪽 차로를 건너는 보행자도 모두 벗어난 뒤에 진입해야 양보입니다.

1단계는 정지 여부를 보지 않습니다. 진입 순간 보행자가 없으면 서행·정지 여부와 관계없이 양보(위반 아님)입니다.

횡단보도 밖에서 건너려는 보행자는 MVP 대상이 아니며, 한계로 밝힙니다.

### 2.3 2단계: 적색 신호 시 정지선 일시정지 판정

**대상:** 차량 신호가 적색인 동안 정지선을 넘어 우회전한 차량. 우회전 전용 신호가 있는 교차로는 제외.

**우회전 구분:** 정지선을 지나는 순간에는 우회전인지 직진인지 알 수 없으므로, 궤적 전체(진입로 ROI → 출구 횡단보도 진입)로 우회전 이벤트를 먼저 확정하고 그 이벤트에만 정지선 판정을 적용합니다(녹화 영상이라 가능). 직진·좌회전 차량은 이벤트가 아니라 멈추지 않아도 대상이 아니며, 녹색·황색 신호의 우회전은 `na`입니다.

**기준 신호등:** 우회전 차량이 접근하는 방향의 차량 신호등(직진 신호, 원형 적·황·녹)입니다. 사람 모양의 보행자 신호등은 쓰지 않습니다. 보행자 신호는 횡단보도 보행자를 위한 신호라 차량의 정지 의무를 가르는 기준이 아닙니다.

**촬영 조건:** 정지선과, 우회전 차량이 접근하는 방향의 차량 신호등이 함께 보여야 합니다. 이 조건이 핵심이므로 촬영 위치를 확정할 때와 2주차 촬영 전에 1주차 영상으로 확인합니다.

| 판정 | 조건 |
| --- | --- |
| 일시정지 | 빨간불일 때 정지선 직전에서 정지(0.5 m/s 이하 1초 이상)한 뒤 진행. 정지선이 없으면 진입 쪽 횡단보도 앞(교차로에 들어가기 전에 건너는 횡단보도)을 기준선으로 씁니다. |
| 미정지 (위반 의심) | 빨간불일 때 정지 없이 정지선을 통과해 우회전 |
| 제외 | 신호 상태 불명, 정지선이 가려짐, 우회전 전용 신호가 있는 교차로 |
| `na` | 녹색·황색 신호(적색만 판정하므로 판정 대상 아님) |

정지 후 우회전할 때 횡단보도에 보행자가 있으면 2.2의 보행자 판정을 이어서 적용합니다. 두 판정은 독립이라 한 이벤트가 두 사유를 모두 가질 수 있습니다.

### 2.4 신호 읽기 (신호등 색 판정)

| 구분 | 방법 |
| --- | --- |
| 영역 지정 | 영상마다 우회전 차량이 접근하는 방향의 차량 신호등(원형 3색)이 찍힌 위치를 사각형으로 한 번 지정(ROI 도구). 신호등이 여러 개 보이면 이 방향 하나만 지정하고, 보행자 신호등·다른 방향 신호등은 지정하지 않습니다. |
| 색 판정 | 프레임마다 그 영역의 빨간 픽셀 비율·HSV 색 규칙으로 판정. 연속 몇 프레임이 같을 때만 상태를 바꿈(초기값 5프레임) |
| 검증 | 사람이 일부 구간의 빨간불 시각을 직접 적어 정답으로 쓰고, 자동 판정과의 일치율을 계산 |
| 쓰임 | 차량과 무관해 먼저 돌려 영상 전체의 빨간불 시간표를 만들고, 판정 때 이벤트의 정지선 통과 시각을 조회합니다. |
| 향후 | 조명·각도에 약하면 작은 분류기를 학습 (향후 과제) |

## 3. 위반율과 대시보드

### 3.1 위반율 정의

| 지표 | 정의 |
| --- | --- |
| 보행자 위반율 | 미양보 ÷ (양보 + 미양보). 판정 대상은 제외를 뺀 모든 우회전이며, 보행자가 없던 우회전도 양보(위반 아님)로 들어갑니다. |
| 적색 위반율 | 미정지 ÷ (일시정지 + 미정지). 판정 대상은 일시정지와 미정지의 합이고, 제외는 들어가지 않습니다. |
| 신뢰구간 | Wilson 95% 신뢰구간. 교차로·시간대마다 따로 계산 |
| 시간대 | 촬영 시작 시각 기준 1시간 단위(예: 08–09시) |
| 참고용 | 판정 대상이 30건 미만인 칸은 "참고용"으로 표시하고, 단속 우선 시간대(TOP 3)는 표본이 충분한 칸에서만 고릅니다(초기값). |

### 3.2 Streamlit 화면 구성

| 영역 | 내용 |
| --- | --- |
| 필터 | 교차로, 기간, 위반 유형(보행자 미양보·적색 미정지·전체), 정렬 기준. "전체"는 두 유형을 나란히 보여 주며, 분모가 달라 하나의 위반율로 합치지 않습니다. |
| 요약 카드 | 판정 대상 건수, 위반 의심 건수, 위반율과 95% 신뢰구간 |
| 위반율 표 | 교차로 × 시간대 행마다 판정 대상, 위반 의심, 위반율(막대·색), 신뢰구간, 신뢰도 배지. 위반율이 높을수록 진한 색 |
| 단속 우선 시간대 | 표본이 충분한 칸 중 위반율 높은 순 TOP 3와 클립 보기 링크 |
| 내보내기 | 현재 필터의 표를 CSV로 내려받기 |

데이터는 이벤트 로그 CSV를 pandas로 모아 표시하고, 화면은 Streamlit의 표·차트·필터·영상 기능을 씁니다.

화면에 "위반 의심 통계이며 실제 단속은 별도 확인이 필요하다"는 문구를 항상 보여 줍니다.

지금 확보하는 데이터는 교차로 1곳이라 한 교차로의 시간대 비교로 채워지고, 교차로 간 비교는 교차로를 추가 촬영하면 같은 화면에 이어서 채워집니다. 교차로를 늘릴 때는 ROI만 새로 지정합니다.

### 3.3 이벤트 로그 (한 줄에 이벤트 1건)

| 필드 | 내용 |
| --- | --- |
| `event_id`, `video`, `intersection` | 이벤트 번호, 영상 이름, 교차로 이름(대시보드 필터 기준) |
| `wall_time`, `slot` | 실제 시각, 시간대(1시간) |
| `vehicle_type` | 승용·버스·트럭·오토바이 (추적 결과의 원래 검출 클래스에서 옮김) |
| `ped_result` | `yield`, `no_yield`, `exclude`, 제외 사유 |
| `red_result` | `stopped`, `not_stopped`, `exclude`, `na`(적색 아님), 제외 사유 |
| `status` | `auto`(규칙 판정) 또는 `reviewed`(사람 확인, 5.2) |
| `peds_at_entry` | 진입 시점 횡단보도 위 보행자 수 |
| `entry_speed` | 진입 속도(m/s, 참고값) |
| `clip` | 위반 의심 클립 경로(3.4) |

### 3.4 위반 의심 클립

미양보·미정지 이벤트 구간을 자동으로 잘라 얼굴·번호판을 블러한 뒤 대시보드에서 보여 주고, 클립 경로(`clip`)를 이벤트 로그에 함께 적습니다. 번호 인식은 하지 않습니다.

## 4. 오류 분석과 고도화

### 4.1 규칙의 오류 분석

정답 구간 영상과 라벨이 달린 이벤트에서 판정이 틀린 사례를 아래 유형으로 나눠 세고, 많은 유형부터 고칩니다.

| 오류 유형 | 설명 |
| --- | --- |
| 추출 누락·오추출 | 우회전을 놓치거나 직진·좌회전을 우회전으로 잡음(ROI 규칙, 추적 끊김) |
| 검출 누락 | 멀리 있는 사람, 가려진 사람, 오토바이를 놓쳐 보행자 수나 차량 궤적이 틀림 |
| ID 전환·끊김 | 추적 ID가 바뀌어 보행자가 벗어난 시점이 틀림 |
| 경계 판정 | 보행자가 횡단보도 경계에 있어 진입 시점 보행자 수가 갈림 |
| 신호 오판 | 신호등 색을 잘못 판정함(조명·각도·가림) |

### 4.2 고도화: 검출 모델 미세조정

| 구분 | 내용 |
| --- | --- |
| 목적 | 멀리 있는 사람과 오토바이를 놓치는 문제를 줄여 판정 정확도를 올립니다. 보행자 수가 틀리면 양보 판정이 바로 틀립니다. |
| 데이터 | 4.1의 검출 누락 장면과 사전학습 모델이 놓친 장면의 프레임을 정답 구간을 뺀 나머지 영상(약 6시간 촬영 시 4개)에서 모아 로컬 라벨러로 라벨링(초기값 약 400프레임). 영상 단위로 학습·검증을 나누고 정답 구간 2개는 쓰지 않습니다. |
| 방법 | Ultralytics YOLO 사전학습 모델을 시작점으로 미세조정 |
| 평가 | 같은 검증 프레임에서 전후의 원거리 사람·오토바이 재현율과 mAP50, 그리고 정답 구간에서 미양보 F1·위반율 오차가 얼마나 좋아지는지 비교합니다. |
| 시점 | 장범수 담당으로 2·3단계와 병행해 11.19~25에 끝냅니다. 오류 분석에서 놓친 사례가 많은 장면부터 시도합니다. |

### 5.2 라벨 종류와 절차

| 라벨 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| 정답 구간 | 영상 2개를 처음부터 보며 우회전 이벤트와 판정을 직접 표시 | 추출 재현율, 위반율 오차, 판정 평가 |
| 이벤트 확인 | 정답 구간을 뺀 나머지 영상(약 4개)에서 추출된 이벤트의 판정을 사람이 확인·수정 | 미양보·미정지 F1 |
| 빨간불 시각 정답 | 일부 구간에서 차량 신호가 빨간불이던 시각(시작~끝)을 사람이 표시 | 신호 색 판정 검증, 미정지 평가 |
| 검출 박스 | 로컬 라벨러 박스(멀리 있는 사람·오토바이 중심) | 4.2 고도화 |

1. 정답 구간 영상 2개(주말마다 1개)를 원본부터 직접 보며 표시합니다.
2. 나머지 영상은 규칙 판정(`auto`)을 출발점으로 사람이 모두 확인해 `reviewed`로 바꿉니다. 평가는 `reviewed`만 씁니다.
3. 이중 라벨링: 60건 이상(약 30%)을 장범수와 육주영이 따로 달아 kappa를 구합니다. 0.7 미만이면 11.16까지 1회만 기준표를 고친 뒤 영향받는 라벨을 다시 답니다(11.1).
4. 중간 발표 전(11.18)까지 정답 구간 1개의 라벨을 끝내 예비 수치를 냅니다.

파이프라인과 신호등 판정을 맡는 김민영은 평가 독립성을 위해 라벨링에서 빠집니다.

## 6. 평가 방법

| 지표 | 목표 | 데이터·방법 |
| --- | --- | --- |
| 미양보 F1 (주 지표) | 0.7 이상 | 정답 구간과 확인된 이벤트 기준. 위반을 놓치지 않는 것이 중요해 미양보 클래스로 잽니다. |
| 미정지 F1 | 값 보고 | 빨간불 시각 정답을 기준으로, 같은 방법 |
| 이벤트 추출 재현율 | 0.8 이상 | 정답 구간 영상 2개에서 파이프라인이 잡은 이벤트 비율 |
| 위반율 추정 오차 | 10%p 이내 | 정답 구간의 정답 위반율 대비. 추출 누락과 판정 오류가 모두 반영되는 최종 지표 |
| kappa | 0.7 이상 | 이중 라벨 60건 이상 |
| 촬영일 간 비교 | 값 보고 | 같은 시간대의 촬영일(두 주말) 간 위반율과 Wilson 구간을 나란히 놓고 겹침을 봄. 건수가 적으면 판단 불가로 적음 |
| 신호 색 판정 일치율 | 값 보고 | 사람이 표시한 빨간불 시각과 자동 판정을 비교 |
| 검출 재현율 (고도화) | 전보다 향상 | 원거리 사람·오토바이, 같은 검증 프레임 |
| 그 외 | 값 보고 | 정밀도·재현율, 판정 대상 건수, 시간대별 위반율과 신뢰구간 |

- 불확실성: 평가 이벤트가 수십 건이면 F1이 크게 흔들리므로 부트스트랩 95% 구간을 함께 냅니다.
- 중간 발표(11.18): 정답 구간 1개로 MVP(보행자 판정)의 예비 수치를 냅니다.
- 시간대별 위반율은 표본이 작아 신뢰구간과 함께 읽어야 한다고 결과에 밝힙니다.

| 단계 | 이름 | 내용 | 시점 |
| --- | --- | --- | --- |
| 0 | 촬영·기준 | 영상 약 6시간, 판정 기준표 확정 | ~11.09 |
| 1 | MVP | 횡단보도 보행자 판정(규칙), 예비 수치 | 11.18 |

| 4 | 검출 고도화 | 멀리 있는 사람·오토바이 파인튜닝, 전후 비교 | 11.19~25 (병행) |
| 5 | 확대 | 교차로 추가(교차로 간 비교), 야간·우천, 신호등·정지선 자동 검출, 준실시간(엣지 분석·이벤트 업로드), 실시간(미정지 후보 → 우회전 확정, 사람 확인 병행) | 향후 과제 |

0~4단계를 11.27까지 구현하고, 4단계는 11.25까지 끝냅니다. 교차로를 늘릴 때는 오류 원인을 가르기 위해 ROI를 수동으로 지정하고, 자동 검출은 그 뒤에 사람 확인과 함께 도입합니다.

## 8. 한계와 대응

| 한계 | 대응 |
| --- | --- |
| 보행자 통행량의 영향 | 보행자가 없던 우회전도 분모에 들어가므로, 보행자가 많은 시간대일수록 위반율이 높게 나올 수 있음. 결과에 시간대별 판정 대상 수와 함께 밝힘 |
| 일반화: 교차로 1곳·낮·맑은 날·주말만 촬영 | 평일 출퇴근은 포함하지 않음. 교차로 간 비교는 확장 과제로 두고, 주장 범위를 한 교차로의 주말 낮 시간대별 비교로 한정. 추가 촬영이 가능하면 평일 1시간 권장 |
| 정지선·신호등이 안 보임 | 촬영 전 확인, 안 보이면 위치 변경, 그래도 안 되면 2단계 범위 축소 |
| 멀리 있는 사람·오토바이 누락 | MVP는 오류로 기록, 4.2에서 미세조정 |
| 횡단보도 밖에서 건너려는 보행자 | MVP는 횡단보도 위 보행자만 보고, 건너려는 의도는 향후 과제 |
| 표본이 작은 시간대 | 신뢰구간 병기, 30건 미만은 참고용 표시 |
| "양보" 기준의 모호함 | 횡단보도 전체 기준으로 단순화하고 이중 라벨링·kappa 확인, 기준은 11.09에 고정 |
| 추적 오류가 판정으로 전파 | 트랙 후처리, 가림 의심 이벤트는 제외 후 확인, 4.2 미세조정 |
| 단속 근거로 쓰기 | 결과는 위반 의심 통계이며 실제 단속은 별도 확인이 필요하다고 화면·발표에 명시. 범칙금·벌점은 발표 전에 법령으로 다시 확인 |
| 촬영 허가·우천 | 후보 위치 2곳, 예비 촬영일 11.14~11.15. 예비일을 쓰면 라벨링 일정을 줄임 |
