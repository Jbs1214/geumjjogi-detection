# 라벨링 가이드

> 담당: 육주영 · 이중 라벨러: 장범수·육주영 (김민영은 평가 독립성 때문에 라벨링하지 않음)

## 1. 이벤트 라벨 (CSV 라벨표)

판정 기준은 `docs/judgment_criteria.md`를 따른다. 영상·라벨러마다 CSV 1개, 위치는 `data/labels/<영상>_<라벨러>.csv`.
인코딩은 UTF-8 with BOM(엑셀 "CSV UTF-8"로 저장). 표는 Drive에 공유해도 된다(영상·이미지는 넣지 않는다).

| 컬럼 | 뜻 | 예 |
| --- | --- | --- |
| `video` | 영상 파일 이름(확장자 제외) | `A_20261031_0800` |
| `event_id` | 영상 안 이벤트 번호. 정답 구간은 라벨러가 매기고, 나머지 영상은 judged의 `event_id`를 그대로 쓴다 | `12` |
| `cls` | `vehicle` / `motorcycle` | `vehicle` |
| `t_enter_s` | 차량이 횡단보도 영역에 진입한 시각(초) | `760.8` |
| `ped_label` | 1단계 보행자: `yield` / `no_yield` / `exclude`. 우회전 경로가 지나는 횡단보도를 모두 보고 판단 | `no_yield` |
| `red_label` | 2단계 정지선: `stopped` / `not_stopped` / `exclude` / `na`(적색 아님) | `na` |
| `labeler` | 라벨러 이름 | `육주영` |
| `note` | 애매한 이유 등 | `보행자 일부 가려짐` |

- **정답 구간**(영상 2개, 주말마다 1개): 원본을 처음부터 보며 모든 우회전 이벤트를 직접 적는다.
- **나머지 영상**: 파이프라인이 뽑은 이벤트(`outputs/judged/`, `status=auto`)를 출발점으로 사람이 모두 확인해 `ped_label`·`red_label`을 적는다. 라벨표에 행이 생긴 이벤트가 `reviewed`이며, 평가는 `reviewed`만 쓴다.
- **이벤트 일치 규칙**: 같은 영상에서 `t_enter_s` 차이가 2초 이내이고 `cls`(차량·오토바이)가 같으면 정답 이벤트와 추출 이벤트를 같은 것으로 본다(`configs/eval.yaml`의 `match_window_s`, 초기값, 기술서 11.1).
- **이중 라벨링**: 60건 이상(약 30%)을 장범수·육주영이 따로 라벨링한다. kappa는 협의 전 두 사람의 라벨로 계산하고, 다르게 단 건은 협의해 합의 라벨을 정답으로 쓴다.
- 기준표가 바뀌면(kappa가 0.7 미만이라 고친 경우 포함) 영향받는 라벨을 다시 단다.

## 2. 빨간불 시각 라벨 (2단계)

- 위치: `data/labels/<영상>_red.csv`. 컬럼 `video`, `t_start_s`, `t_end_s`, `labeler` (한 행 = 빨간불 구간 1개).
- 일부 구간에서 우회전 차량 방향 차량 신호등(직진 신호)이 빨간불이던 시작~끝 시각을 사람이 적는다. 보행자 신호등은 보지 않는다.
- 쓰임: 신호 색 판정 일치율, 미정지 F1.

## 3. 박스 라벨 (검출 고도화 단계)

- 도구: 로컬 **labelImg**, 저장 형식 **YOLO**. 클라우드 라벨링 도구에 원본 프레임을 올리지 않는다.
- 대상: 기술서 4.1 오류 분석에서 검출 누락으로 분류된 장면과 사전학습 모델이 놓친 장면의 프레임(초기값 약 400프레임). 멀리 있는 사람·오토바이 중심. 학습·검증은 영상 단위로 나눈다.
- 프레임은 정답 구간 영상 2개를 뺀 나머지 영상에서만 모은다(정답 구간은 전후 비교에만 쓴다).
- 범위: 프레임 안에 보이는 vehicle·motorcycle·pedestrian을 **모두** 단다(ROI 밖 포함). 박스 높이 12픽셀 미만이거나 절반 넘게 가려진 대상은 달지 않는다(초기값).
- 클래스 ID: `0 vehicle`, `1 motorcycle`, `2 pedestrian` (`configs/detect.yaml`)
- 위치: `data/boxes/images/`, `data/boxes/labels/`
- 오토바이 운전자는 따로 박스를 치지 않는다(오토바이 박스에 포함). 자전거·전동킥보드 탑승자는 라벨하지 않는다(향후 과제).
- 모델 비교(YOLO11n vs YOLO26s)는 따로 라벨을 만들지 않고 위 검증 프레임(약 80장, 초기값)으로 한다.
